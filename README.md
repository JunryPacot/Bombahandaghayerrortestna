📱 SMS Bomber — Educational Project

Website: https://bombahan.freedev.app

⚠️ Educational Purpose Only

This project was developed independently by Junry Pacot as an educational and experimental project.

The purpose of this project is to learn about:

- Web application development
- API integration
- HTTP requests and responses
- SMS service integrations
- Web security and responsible API usage
- Rate limiting and abuse prevention
- How different online services communicate with web applications

I developed and tested this project on my own for learning and experimentation.

🚨 Responsible Use Notice

This tool must not be used to harass, annoy, threaten, or intentionally disturb another person.

Do not use this project to:

- Send unwanted messages to other people
- Spam phone numbers
- Flood SMS services
- Bypass API or provider restrictions
- Abuse third-party services
- Attack or disrupt telecommunications providers
- Send messages without proper authorization
- Violate the terms of service of any API or website

Only perform testing on phone numbers, systems, and services that you own or have explicit permission to test.

🧪 My Testing

🔐 Responsible Development

This project is also intended to demonstrate why developers should consider:

- Rate limiting
- Request validation
- Abuse prevention
- Authentication
- API security
- Logging and monitoring
- CAPTCHA or other anti-abuse mechanisms
- Provider terms and usage restrictions

Developers building similar systems should implement appropriate safeguards instead of allowing unlimited requests.
